# Paired causal fields and single-direction steering: code, analysis plans and results

This archive accompanies the manuscript "Paired interventions show when a single direction suffices to steer a
neural network". Every number in the manuscript and its appendix is generated by `paper/make_numbers.py` from the
files in `results/summary/`.

## Layout
- `plans/`: the analysis plans, written before the corresponding results (PREREG.md, PREREG_ADDENDUM.md,
  PREREG_2.md, PREREG_E2.md with amendment A1). Their modification times and checksums are listed in `plans/CHECKSUMS`.
- `paper/make_numbers.py`: writes every number quoted in the manuscript as a LaTeX macro from `results*/summary/`.
- `code/`: all analysis code. Simulations: `sims.py`, `sims_flatness.py`. Language models: `data_prep.py`,
  `gen_refusal_pairs.py`, `extract.py`, `analyze_fields.py`, `scan_dirs.py`, `steer.py`, `gen_check.py`, `grads.py`.
  Aggregation: `aggregate.py`, `explore_unitfidelity.py`, `analyze_scan.py`, `analyze_grads.py`,
  `explore_grads_alpha.py`, `gen_audit.py`. Figures: `make_figs.py`. Estimators: `fieldstats.py`.
- `run_model.sh`: the whole pipeline for one model (set CMA_ROOT, PY, HF_HOME).
- `data/`: the paired data sets (`pairs_*.jsonl`) and the generated harmless rewrites of AdvBench requests.
- `results/sims/`: seed-level simulation outputs.
- `results/fields/`: per-layer field indices, held-out scores and diagnostics (JSON) for every model and data set.
- `results/steer/`, `results/scan/`: per-unit outcomes of every steering condition (`.npz`: unsteered score T0, steered
  score T, KL and off-target KL per unit) with metadata and verification reports.
- `results/states/`: per-unit families and readout scores of each input and its counterfactual (groups, Ta, Tb).
  Full activations are not included (several hundred GB); `extract.py` regenerates them from the pinned revisions.
- `results/gen2/`: every generated text, per condition, with the refusal rule's per-item decision.
- `results/grads/`: readout-gradient summaries and gate values (full gradient arrays are regenerated by `grads.py`).
- `results/summary/`: all tables used in the manuscript.
- `audit/`: the audit sample of the refusal rule and its labels.
- `results_e2/`: the same layout for the pre-specified replication on five larger models (Qwen2.5-14B-Instruct,
  Qwen2.5-32B-Instruct, phi-4, Mistral-Small-24B-Instruct-2501, OLMo-2-1124-13B-Instruct; bfloat16; steering run with
  `steer.py --nocache`, see amendment A1 in `plans/PREREG_E2.md`). `results_e2/summary/t0_agreement.json` gives the
  agreement of the steering-pass and extraction-time scores.
- `results_all/summary/`: every test on all eleven models pooled (built from `results/` and `results_e2/` together).

## Reproducing the tables
```
python code/aggregate.py --root results
python code/explore_unitfidelity.py --root results
python code/analyze_scan.py --root results
python code/analyze_grads.py --root results
python code/gen_audit.py --root results --audit audit
python code/make_figs.py --root results
python paper/make_numbers.py results/summary numbers.tex
```
The same commands with `--root results_e2` reproduce the replication tables. For the pooled tables, copy the files of
`results/{fields,steer,scan,states,gen2}` and `results_e2/{fields,steer,scan,states,gen2}` into one directory tree and
run the same commands on it. `python code/t0_agreement.py --root results_e2` writes the score-agreement summary.
`python paper/make_numbers.py results_e2/summary numbers_e2.tex E` and `python paper/make_numbers.py
results_all/summary numbers_all.tex All` write the macros of the replication and the pooled analysis.

## Models
See `MODELS.md` for the Hugging Face revisions. The six-model study ran in float32 (PyTorch 2.8, transformers 4.56);
the replication on five larger models ran in bfloat16 (PyTorch 2.10, transformers 4.57) with `steer.py --nocache`.

## Safety note
`data/pairs_advbench.jsonl` contains the public AdvBench requests and harmless rewrites. No harmful completion was
generated at any stage; generation was run only on the harmless rewrites.
